# robotics_final_project

Problem1은 SLAM을 활용한 랜드마크들의 위치 추정 알고리즘 코드이다.

Problem23는 로봇이 자신의 위치를 모르는 상황에서 랜드마크들과의 거리를 센싱할 때 particle filter 알고리즘을 사용하여 자신의 위치를 추정한다. 이후 목적지까지 A* 알고리즘을 통해 경로를 설정하고 PID 제어를 통해 목적지까지 이동하는 코드이다.

Problem45는 Problem23에서 로봇이 랜드마크들과의 거리를 센싱하지 않고 반경 8m거리의 모든 장애물을 인식하고 목적지까지 이동하는 코드이다.
